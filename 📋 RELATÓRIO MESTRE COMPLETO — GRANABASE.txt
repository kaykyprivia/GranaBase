2. REGRAS DE TRABALHO (NÃO NEGOCIÁVEIS)
- 1 comando por vez no PowerShell
- Nunca rodar git reset --hard ou git checkout . (exceto arquivo específico)
- Nunca expor .env.local ou secrets
- Antes de commitar: npm run typecheck + npm run test + npm run build
- Migrations: abrir via Start-Process "supabase/migrations/arquivo.sql" e colar no painel SQL
- Mudança de retorno de RPC: precisa DROP FUNCTION antes de CREATE OR REPLACE
- Cuidado com ambiguidade de nomes em PL/pgSQL (usar prefixo v_)
- PowerShell Set-Content -Encoding utf8 adiciona BOM em arquivos LF. Preferir scripts Node
- Arquivos alternam entre LF e CRLF — usar .split("\n").join(eol) com detecção
- Para substituições complexas: usar Node com regex robusto ou substituição por linha única
